About & honesty notes

Agent Passport is a free on-chain activity record. Checking in writes your daily presence to the AgentPassport smart contract (0xff47c1d24884660d5d7de472cc5172f8ad3a6c6b) and costs only the network gas fee (a fraction of a cent). It is not an investment, not a token, and it promises no returns, rewards, or future value of any kind.

Only wallets that hold an Agent ID (the soulbound identity NFT issued through the Binance app) can check in — the contract verifies this on-chain on every check-in. The contract has no owner, no admin keys, and no payable functions: it can never hold funds, and nobody can edit or delete your passport. Source code is open and verified — see the project repository.

This page connects through your wallet's standard injected provider only. It never asks for a seed phrase, a private key, or any pairing code, and every transaction is shown and confirmed by you in your own wallet first.
